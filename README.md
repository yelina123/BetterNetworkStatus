# BetterNetworkStatus

一个为 [ClassIsland](https://classisland.tech) 设计的轻量网络延迟显示插件。

用四格信号条直观展示网络质量，体积远小于纯文字组件，适合放在 island 主界面的紧凑区域。

## 功能

- **信号条显示**：四格递增高度的信号条，一眼看出网络好坏
- **三色分级**：绿色（优秀）/ 黄绿（良好）/ 橙色（一般）/ 橙红（较差）
- **三种显示样式**：仅信号条 / 信号条+数字 / 仅数字
- **单色模式**：信号条统一白色，不随延迟变色（适合极简主题）
- **双检测模式**：ICMP（精确低耗）/ HTTP（兼容代理）/ 自动
- **自定义阈值**：可调整优秀/良好/较差的延迟分界值
- **可调刷新间隔**：1-60 秒

## 信号等级

| 等级 | 信号条 | 颜色 | 默认延迟范围 |
|------|--------|------|-------------|
| 优秀 | 4 格 | 亮绿 | < 50ms |
| 良好 | 3 格 | 黄绿 | 50-100ms |
| 一般 | 2 格 | 橙色 | 100-300ms |
| 较差 | 1 格 | 橙红 | > 300ms |
| 离线 | 0 格 | 灰色 | 超时/不可达 |

## 构建

```bash
dotnet build -c Release
```

构建产物在 `bin/Release/net10.0-windows10.0.19041.0/win-x64/` 下，将整个文件夹复制到 ClassIsland 插件目录即可。

## 安装

1. 构建或下载发布包
2. 将插件文件夹放入 ClassIsland 的 `Plugins` 目录
3. 重启 ClassIsland
4. 在主界面编辑模式下添加「迷你网络延迟」组件
